# BPMと演奏時間

全曲のJSONに `bpm`（基本）、`bpmMin`（下限）、`bpmMax`（上限）、`durationSeconds`（ゲーム内演奏時間・整数秒）を用意しています。BPMは小数に対応し、未確認はnullです。一定のBPMは基本だけでも登録できます。変動する場合は上下限を両方登録します。

管理ページの新規追加・既存曲修正で同じ4欄を使用します。例えば1分45.983秒は秒未満を切り捨てて105秒と入力し、詳細では1:45と表示します。入力内容は他の欄と同じように端末の下書きへ保存されます。以前の小数入り下書きは、読み込み時に整数へ切り捨てます。

一覧の「BPM順」は初回選択で基本BPMの降順、「演奏時間順」は秒数の降順です。選択中のボタンを再度押すたびに通常順（▲）と逆順（▼）が切り替わります。同値は既存のバンド→種類→配信順で比較し、逆順ではその順序も反転します。未確認は常に最後です。検索・絞り込み・ページ移動と併用できます。難易度の選択はBPM順・演奏時間順に影響しません。

## 2026年9月18日の既存曲調査

Bestdori!の公開データの日本版曲名を、既存の全796曲と照合しました。演奏時間はゲーム版の`length`で、音源のフルバージョンの時間や最初から最後のノーツまでの差ではありません。

基本BPMはEXPERTのBPM区間ごとの秒数を同じBPM別に合計し、最長の値を採用しました。同時間なら最初に現れた値を採用します。下限・上限は実際に正の時間続く区間の最小値・最大値です。時間0の初期化イベントは除きます。これはこのサイトでの基本BPMの定義であり、公式の指定値を意味しません。

84曲にBPM変動があります。オトナブルー・人マニア・壱雫空では難易度によって変化時刻にわずかな差がありますが、基本・下限・上限の結果は同じです。

手動追加されたResound the Wayはこのサイトの管理ID821に対して外部ID812です。曲名とRoselia（外部bandId 5）を確認して対応付けました。管理ID821の外部曲「ライムライト」とは混同していません。既存の管理番号、タイトル、ノーツ等は変更していません。

調査元のID・区間・元データのSHA256・元の小数秒は `data/garupa/song-timing-research.json` に保存しました。公開するBPMと整数秒は `data/garupa/songs.json` にだけ置き、同じ値を調査記録に重複させません。調査記録はIDで曲と対応し、出典URLは `sourceId` から求められます。調査時に未収録だった「ライムライト」には記録がありません。公開ビルドには調査ファイルを含めません。`scripts/research/song-timing.mjs` は保存済みの公開データを読む調査用ツールです。通常のビルドは外部取得せず、手動編集した値を保持します。再調査で既存の数値が異なる場合は上書きを拒否します。

出典から転記した値であり、ゲーム実機で全曲のストップウォッチ計測を行ったものではありません。
