# BPMと演奏時間

全曲のJSONに `bpm`（基本）、`bpmMin`（下限）、`bpmMax`（上限）、`durationSeconds`（ゲーム内演奏時間・秒）を用意しています。小数に対応し、未確認はnullです。一定のBPMは基本だけでも登録できます。変動する場合は上下限を両方登録します。

管理ページの新規追加・既存曲修正で同じ4欄を使用します。例えば1分45.384秒なら演奏時間に105.384を入力します。詳細では1:45.384と表示します。入力内容は他の欄と同じように端末の下書きへ保存されます。

一覧の「BPM（速い順）」は基本BPMの降順、「楽曲演奏時間（長い順）」は秒数の降順です。同値は既存のバンド→種類→配信順。未確認は最後に表示します。検索・絞り込み・ページ移動と併用できます。

## 2026年9月18日の既存曲調査

Bestdori!の公開データ https://bestdori.com/api/songs/all.7.json の日本版曲名を、既存の全796曲と照合しました。演奏時間はゲーム版の`length`で、音源のフルバージョンの時間や最初から最後のノーツまでの差ではありません。

基本BPMはEXPERTのBPM区間ごとの秒数を同じBPM別に合計し、最長の値を採用しました。同時間なら最初に現れた値を採用します。下限・上限は実際に正の時間続く区間の最小値・最大値です。時間0の初期化イベントは除きます。これはこのサイトでの基本BPMの定義であり、公式の指定値を意味しません。

84曲にBPM変動があります。オトナブルー・人マニア・壱雫空では難易度によって変化時刻にわずかな差がありますが、基本・下限・上限の結果は同じです。

手動追加されたResound the Wayはこのサイトの管理ID821に対して外部ID812です。曲名とRoselia（外部bandId 5）を確認して対応付けました。管理ID821の外部曲「ライムライト」とは混同していません。既存の管理番号、タイトル、ノーツ等は変更していません。

調査値・区間・曲ごとの参照URL・元データのSHA256は `data/research/song-timing.json` に保存しました。公開ビルドには調査ファイルを含めません。`scripts/research-song-timing.mjs` は保存済みJSONを読む一度限りの調査用ツールです。通常のビルドは外部取得せず、手動編集した値を保持します。再調査で既存の数値が異なる場合は上書きを拒否します。

出典から転記した値であり、ゲーム実機で全曲のストップウォッチ計測を行ったものではありません。
