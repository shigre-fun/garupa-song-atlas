# 楽曲データの記入方法

`node scripts/add-song.mjs "楽曲名"` で、このひな型から編集用ファイルを作成できます。
JSONでは文字列を半角の二重引用符で囲み、最後の項目の後にはカンマを付けません。コメントは書けません。

| 項目             | 記入する内容                                                                |
| ---------------- | --------------------------------------------------------------------------- |
| `id`             | 自動割り当てされる管理番号。既存曲と重複不可                                |
| `title`          | 表示する正式な楽曲名                                                        |
| `reading`        | 50音順用の読み。英語の曲もカタカナで入力                                    |
| `category`       | `オリジナル`、`カバー`、`エクストラ`                                        |
| `band`           | 演奏バンド名。エクストラは `Roselia×参加アーティスト名` 等                  |
| `releaseDate`    | 日本版の配信日時。例：`2026-09-17T15:00:00+09:00`                           |
| `releaseOrder`   | 同時配信曲の順序。小さい数を先に表示                                        |
| `composer`       | オリジナルの作曲者、またはカバー・エクストラの原曲作曲者                    |
| `originalArtist` | 原曲アーティスト。オリジナルや未確認の場合は `null`                         |
| `originalWork`   | 原曲が使用されたアニメ・映画等。複数あれば区切って入力。未確認は `null`     |
| `live3d`         | 3Dライブあり：`true`、なし：`false`、未確認：`null`。オリジナルの詳細で表示 |
| `aliases`        | 検索用別名の配列。例：`["作品の略称", "曲名の別表記"]`。不要なら `[]`       |
| `difficulties`   | EASY・NORMAL・HARD・EXPERT・SPECIALの5項目                                  |

各難易度は、例のようにレベルとノーツ数を記入します。

```json
"EXPERT": {
  "level": 26,
  "notes": 850
},
"SPECIAL": null
```

未実装の難易度は `null` にします。未確認の譜面数値を仮の値で公開しないよう、ゲームで確認して記入してください。
バンド順に認識される表記は `Poppin'Party`、`Afterglow`、`Pastel＊Palettes`、`Roselia`、`ハロー、ハッピーワールド！`、`Morfonica`、`RAISE A SUILEN`、`MyGO!!!!!`、`Ave Mujica` です。
その他のバンドや複数バンドの合同曲は「その他」に入ります。
